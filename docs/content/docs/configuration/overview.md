# Configuration overview

<figure markdown="span">
    ![Navbar Card with five routes](../../img/navbar-card.png#only-light){ width="456" }
    ![Navbar Card with five routes](../../img/navbar-card_dark.png#only-dark){ width="456" }
</figure>

| Name           | Type                               | Default    | Description                                        |
| -------------- | ---------------------------------- | ---------- | -------------------------------------------------- |
| `routes`       | [Routes](routes.md)             | `Required` | Array of navigation items to display in the navbar |
| `desktop`      | [Desktop](desktop.md)           | -          | Desktop-specific layout and behavior settings      |
| `mobile`       | [Mobile](mobile.md)             | -          | Mobile-specific layout and behavior settings       |
| `layout`       | [Layout](layout.md)             | -          | General layout configuration                       |
| `styles`       | [Styles](styles.md)             | -          | Custom CSS styling options                         |
| `template`     | [Navbar templates](../advanced/navbar-templates.md) | -          | Predefined template to use as base configuration   |
| `haptic`       | [Haptic](haptic.md)             | -          | Configure haptic feedback on interactions          |
| `media_player` | [Media Player](media-player.md) | -          | Media player widget integration           |
