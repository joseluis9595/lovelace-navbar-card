## Contributing

Help improve the project by:

- [Submitting pull requests](https://github.com/joseluis9595/lovelace-navbar-card/pulls)
- [Reporting bugs](https://github.com/joseluis9595/lovelace-navbar-card/issues)
- [Suggesting features](https://github.com/joseluis9595/lovelace-navbar-card/discussions/categories/ideas)
- [Improving the documentation](https://github.com/joseluis9595/lovelace-navbar-card/tree/main/docs)
- [Sharing examples](https://github.com/joseluis9595/lovelace-navbar-card/discussions/categories/show-and-tell)

## Community support

Help grow the community by:

- Sharing your experience
- Helping others in the forums
- Creating tutorials or guides
- Showcasing your setup

## Thank you! 🙌

Your support means a lot and helps keep the project alive and growing. Whether you contribute through financial support, code contributions, or community involvement, every bit helps make Navbar Card better for everyone.
